## Qué demuestra esta prueba

Que el sistema funciona de extremo a extremo con un navegador real, no solo
con el test client de Flask (pytest) ni con curl (smoke_test_manual_v1.0.md):
- El frontend HTML/CSS/JS real hace las peticiones correctas a la API real.
- La sesión, el CSRF y las cookies funcionan tal como las manejaría un
  navegador de verdad (Playwright usa un motor de navegador real, Chromium).
- La Content-Security-Policy configurada en el backend no rompe ningún
  script del frontend (si lo hiciera, ninguna de estas pruebas habría
  podido hacer clic ni enviar un formulario).
- El flujo de negocio completo (reportar → buscar → coincidencia →
  solicitar → verificar → aprobar) funciona con datos reales persistidos
  en la base de datos, no simulados.

## Limitación de esta evidencia

Al igual que smoke_test_manual_v1.0.md, esta prueba corrió sobre
localhost. La prueba sobre la URL pública desplegada debe repetirse y
documentarse aparte cuando exista esa URL (ver docs/DEPLOYMENT.md).
